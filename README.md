# itsumair.com

Website for Muhammad Umair: web design, SEO, digital marketing and AI automation.

Built with Next.js (App Router), React and Tailwind, on a custom design system.

## Develop

```bash
npm install
npm run dev
```

## Environment

Copy `.env.example` to `.env.local` and fill in the Resend values for the contact form.

## Build

```bash
npm run build
npm run start
```
